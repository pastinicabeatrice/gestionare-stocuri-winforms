Proiect de Gestiune stocuri

Structura:
Pentru implementarea funcționalităților s-au implementat mai multe fișiere distribuite astfel:
Clasele Material.cs si Operatie.cs se gasesc in folderul Classes

Testare în FormMateriale:

Apasă Alt + A pentru a adăuga un material.
Apasă Alt + U pentru a actualiza un material selectat.
Apasă Alt + Ș pentru a șterge un material selectat.
Apasă Alt + N pentru a muta cursorul în câmpul Nume.
Apasă Alt + C pentru a muta cursorul în câmpul Cantitate.
Apasă Alt + P pentru a muta cursorul în câmpul Preț.
Apasă Alt + F pentru a muta cursorul în câmpul Furnizor.
Testare în FormOperatii:

Apasă Alt + A pentru a adăuga o operație.
Apasă Alt + U pentru a actualiza o operație selectată.
Apasă Alt + Ș pentru a șterge o operație selectată.
Apasă Alt + M pentru a muta cursorul în Material Utilizat.
Apasă Alt + O pentru a muta cursorul în Tip Operatie.
Apasă Alt + C pentru a muta cursorul în câmpul Cantitate.
Apasă Alt + D pentru a muta cursorul în Data Operatie.
